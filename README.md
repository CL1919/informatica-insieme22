# informatica-insieme22
Un progetto per imparare informatica in modo semplice e pratico. Il sito propone guide per avvicinarsi a HTML e CSS, idee per creare i primi progetti, percorsi di studio e aggiornamenti sui corsi online. L’obiettivo è aiutare chi parte da zero a imparare, sperimentare e sviluppare le proprie idee passo dopo passo.
